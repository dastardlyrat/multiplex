## Capture Guidance

- Prefer a clean real-world inbox example with non-sensitive sample content.
- Keep text readable at listing scale; avoid tiny-font captures.
- Show meaningful state (not empty panes) wherever possible.
- Use consistent browser zoom and window size across screenshots.
- Redact or replace any personally identifying email content before capture.
