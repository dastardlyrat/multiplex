URL Forensics Workbench

infoAbout

URL Forensics Workbench is a local URL forensics workbench for reviewing links found in supported webmail message bodies.

Local helper URL forensics Supported webmail No debug trace persistence

travel_explorePurpose

The extension detects the currently opened email body, extracts URLs, and presents a workbench for reviewing detected, normalized, resolved, final, digest, mirror, and diagnostic output.

lockPrivacy Model

Security transparancy actualized by information ethics.

Local operation

The helper works in the browser extension context and supported webmail pages. It does not require a remote service for the extension UI pages.

Stored choices

Settings, sender-address choices, and debug output choices can be stored in extension storage so the UI remembers them.

Debug traces

Program debug trace output remains in memory only. It can be exported manually from the Debugging page, but it is not persisted automatically.

hubPage Map

Settings

Change URL normalization, mirror replacement, and sender-address auto-apply behavior.

Trackers

Choose which known tracking query parameters are removed when tracking-parameter stripping is enabled.

Diagnostics

Inspect active-tab detection state for the currently selected supported webmail tab.

Debugging

Control program debug levels and categories, view the live in-memory trace, clear output, or export JSON.

Storage

Inspect stored choices and whether each storage-backed option is default, stored default, or stored custom.
