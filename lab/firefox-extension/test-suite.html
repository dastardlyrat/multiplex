Expected Classification Matrix

Clean direct URLs should remain destination.

Known tracking parameters left in place should label final href text as tracker.

Known tracking parameters that are removed should label final href text as tracker cleaned.

Email addresses, mailto: links, and safe contact-style parameters should not be promoted to tracker status.

Wrapped destinations should be classified by the resolved final destination, not just the wrapper host.

Expected Debug Signals

  • Detection mode should read as full-page-read.
  • The workflow tracker pane should show removed parameter names when stripping is enabled.
  • The hover breakdown should place known tracker parameters in Tracker Parameters and non-trackers in Other Parameters.
  • The final href label should show tracker when tracker parameters remain and tracker cleaned when they are stripped.
  • Wrapper cases should demonstrate whether the resolver is peeling url, target, redirect_url, and continue consistently.
